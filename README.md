# Good Growth Game — คุณเป็นคนยั่งยืนสายไหน?

แบบทดสอบ 8 ข้อ วัดว่าคุณเป็น "คนยั่งยืนสายไหน" พร้อมแผนที่พลัง (radar chart) 5 ด้าน

- สายวางแผน · สายลงมือทำ · สายดูแลคน · สายเล่าเรื่อง · สายปกป้อง

## โครงสร้าง

เป็นเว็บ static ไฟล์เดียว (`index.html`) — ไม่มี build step ไม่มี dependency
เปิดไฟล์ในเบราว์เซอร์ได้ทันที หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000
